# 接点駆動法（せってんくどうほう / Contact-Driven Motion）

体育の動きを模擬人形で再現する時の作り方。側転（`motions/cartwheel/`）で確立した（2026-11-20）。
各項目に根拠の強さを付す：**確認済み**（この方式で作って数値・画面で確かめた）／**仮説**（理由の説明として立てたが未検証）。

## 1. 一言で

**姿勢を角度で指定しない。「手足が床やボールにつく点と時刻（接点）」と「腕を伸ばす等の条件」を先に置き、体の位置と傾きはそこから計算する。**

体は、支えている点に従って動く。人が手で体を支える時、肩は手の上に来て腕は伸びる。
作者が腰の通り道を想像で置くと、この支えの形と食い違い、腕の曲がり・頭と腕の重なり・不自然な腰の位置として現れる。（確認済み：側転の第1〜5版はこの食い違いが原因だった）

## 2. 作る順序

| 順 | すること | 入れるもの |
|---|---|---|
| 1 | 手本動画をコマで読む | 1秒あたり12〜30コマで切り出し、局面ごとの時刻・接点・形の構造を書き出す（`motions/<名前>/notes.md`） |
| 2 | 接点表を作る | どの手足が、どの点に、いつからいつまでつくか |
| 3 | 体の大まかな道筋を置く | 骨盤の位置・体の向き（数か所だけ）。細部は合わなくてよい |
| 4 | 条件を置く | 例：支えている腕は伸ばす／床の足は母指球で向きを変える／頭と腕は重ならない |
| 5 | 解く | 下の §3 の順で計算する |
| 6 | 検証する | §5 の5項目を数値で測り、画面で照らし合わせる |

**形の構造は動画からしか分からない。** 例：側転の起き上がりで、腕は単独で振り戻さず横に伸ばしたまま体と一緒に起こす／後からついた手は長くマットに残る。数値の調整では出てこない。（確認済み）

## 3. 解く順序（実装の要点）

1. **体の道筋を細かく標本化してならす**：1/120秒ごとに計算し、前後を重み付きで平均する（ガウス、σ≈0.04〜0.07秒）。区切りでの速さの急変を消す。
2. **骨盤は胴ほど回さない**：胴の回転の一部（側転の踏み込みで約7割）だけ骨盤に与え、残りを腰と背中に分ける。股関節の可動域を超えないため。（確認済み：一体で回すと股関節が約170°曲がった）
3. **条件で体を補正する**：支えている手について「肩が手から腕の長さの所に来る」ように、体を平面内で回して動かす（両手なら2点合わせ）。補正量も時間方向にならす（σ≈0.025秒。大きいと補正が遅れてひじが曲がる）。
4. **手足の目標点を決める**：空中の軌道は体に対する向きで置いてならし、接点とは重みで混ぜる。
   重みは、つく前は減速しながら近づき（smoothstep）、離れる時はゆっくり離れる。混ぜる時間は前後の接点までの間の半分（最大0.2秒）。
5. **2関節の逆運動学で腕・脚を解く**：伸びきる直前（長さの99%から）だけやわらかく止める。
   ひざ・ひじの向き（ポール）は、空中では骨盤・胸の前方、床についている間はつま先の水平方向に置く。（確認済み：骨盤が前へ倒れると、骨盤基準のポールが太ももと平行になり、ひざが後ろへ折れた）
6. **足首・手首**：床についている間は足の裏・手のひらを床に。足先は骨盤の向きへ回す（母指球で向きを変える）。
7. **再生の時間配分**は姿勢と分けて持つ（時間の進め方の表）。「倒立が長い」等の指摘は姿勢を変えずに直せる。

## 4. タメ・解放・反動が出る理由（仮説）

利用者の評価（2026-11-20）：「タメと解放、反動が表現できている」。理由の仮説：

- **補正が体を押し引きする**：腕を伸ばす条件は、体を手から腕の長さの所に保つ。回転が続くと体は押し出され、離れると戻る。ばねのような押し引きになる。
- **ならしが前後に広がる**：前後対称の平均は、出来事（手をつく・離す）の少し前から体を動かし始め、少し後まで動きを残す。アニメーションの「予備動作」「後追い」に当たる。
- **接点への減速と、ゆっくり離れる重み**が、止まる・放つのリズムを作る。

検証方法の案：ならしを切った版・補正を切った版と見比べ、利用者に判定してもらう。（未実施）

## 5. 検証（数値で測る5項目）

`tools/verify/check.js` で測る。画面で必ず照らし合わせる（測り方自体が誤ることがある：頭の判定で目の部品を拾った例がある）。

| 項目 | 目安 |
|---|---|
| 接点に届いているか | 重み1の間の外れ 3cm 未満 |
| 加速度の急な振れ（関節位置の2階差分） | 手首・足首・ひじ・ひざ・頭。数百 m/s² 台なら、なめらかに見えた。1000超は引っかかりとして見えた |
| 関節の可動域 | 股関節の曲げ 約120°（ひざを曲げた時）・ねじれ ±45°、ひざ 0〜150°で逆に曲がらない、足首 背屈20°・底屈50° |
| 頭と腕の重なり | 頭の楕円体を腕の太さぶん膨らませて判定。中に入らない |
| 支えている腕の伸び | ひじ 20°以下 |

## 6. やってはいけないこと（失敗から）

- **症状への継ぎはぎ**：頭と腕の重なりを「手の目標を頭から押しのける」で直そうとして、加速度が2000を超えた。根本（胴の向き）を直すと重なりは消えた。
- **接点の切り替えを短くする**：0.07秒の切り替え・0.08秒の踏み出しは、ぎこちなさの主因だった。
- **床の点を固定したまま周りだけならす**：固定点とならした隣の点の間に段差ができる。ならすのは空中の軌道だけにして、接点とは後から重みで混ぜる。
