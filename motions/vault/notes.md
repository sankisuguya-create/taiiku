# 跳び箱（開脚跳び・かかえ込み跳び・台上前転）：手本の読み取り記録

- 出典：「とび箱 お手本 17技」（YouTube）。動画は置かない。横からの固定カメラ、ほぼ実際の速さ。
  開脚跳び 0:13〜0:22、台上前転 0:38〜0:46、かかえ込み跳び 1:05〜1:13 を1秒4コマで読んだ（チェストパスより粗い）。
- 選んだ理由：学習指導要領解説の中学年の基本技（切り返し系＝開脚跳び、回転系＝台上前転）と、開脚跳びの発展技（かかえ込み跳び）。

## こつ（出典）
- 開脚跳び：両足をそろえて「トン」と踏み切る／跳び箱の奥に両手をそろえて「パン」と着く／両手で「グッ」と突き放して着地（鹿児島県の資料）。着地はひざを曲げる（京都市の資料）。
- 台上前転：両足で踏み切り、腰の位置を高く保って着手し、前方に回転して着地（千葉県の単元計画）。
- かかえ込み跳び・台上前転の頭の着き方（あごを引き後頭部を着く）は一般的な指導の要点で、資料では未確認。

## 接点駆動法での作り
- 接点：助走の2歩と踏み切り板の両足／跳び箱の上の両手（指は進む方向）／着地マットの両足。台上前転は「頭→背中→腰が跳び箱の上面に触れる」条件で体の高さを決める。
- 支える腕を伸ばす補正は、両手が左右に並ぶので「回転なし・移動だけ」にした（側転の回転を流用すると両手が届かず最大41cm離れた）。
- 開脚跳び・かかえ込み跳びは、着手の間の体を前傾80°前後にし、腰を高くした（低いと脚が跳び箱に入った）。

## 検証（2026-11-21）
- 手は跳び箱に届いている。関節の点が跳び箱の中に入る所はない（3技とも）。
- 助走の最初の一歩で足が最大8cm浮く（見た目への影響は小）。
- 未確認：通しての再生、実際の速さとの対応、台上前転で頭が着く位置の正確さ。
- 左右の足の位置の取り違え（進む方向+Xを向くと左は−Z）を修正し、腕・脚が中心線を越えない制約（MQ.noCross）を追加（2026-11-21）。跳び箱は台形の一体形。
- 台上前転を作り直し（2026-11-21）：「転がる点」を手の少し先（x=0.26）から跳び箱の奥（0.66）へ動かし、体のいちばん低い所（頭・首・肩・背中・腰）をその点に合わせる。補正量は全時間で求めてならす。
  その後、腕・脚・胴の線上の点で跳び箱へのめり込みを測り、前後の最大をとってならした押し上げを足す（4回）。引き下げは使わない（前後と食い違ってガタついた）。
- ひざの交差：ひざが中心線に近づくほど曲がる向きを連続的に外へ寄せる（急な切り替えはひざが跳ねた）。床についている足には使わない。
- 検証：3技とも、腕・脚・胴の線上の点の跳び箱へのめり込み0cm、ひざの交差なし。
- 2026-11-21：空中の重心を放物線に従わせた（放物線から外れるのは接点の境目の4コマだけ）。踏み切り板を跳び箱の側が高いくさび形にし、足を上面に合わせた。空中でつま先を伸ばす。
  かかえ込み跳びは、腕と脚が重ならないよう、手を少し広く着き、突き放しを早め（0.93秒）腕を開いてから脚を通す形にした。体の部品どうしの重なりは5つの動作すべてでなし。
- 2026-11-21 再開：前転のページで作った仕組みを移した。台上前転は背中の線の上を連続して動く接点で転がり（頭の後ろ x 0.22 から）、回る間の脚は「前転の姿勢」と同じ角度（股関節約120°・ひざ約140°）。かかえ込み跳びの空中の脚も角度で抱え込む（股関節約115°・ひざ約138°）。角度で決めるのは踏み切り後〜着地の間だけ（助走は従来どおり）。
  3技とも着地後に両手を上げる。検証：めり込み0cm・ひざの交差なし・体の部品どうしの重なりなし・空中は放物線（外れは接点の境目の4コマ）。
- 2026-11-21：台上前転の頭のめり込みを修正。頭（球）も跳び箱の端の外30cmまでは上面より下げない。めり込みの測り方を、転がりの接点と同じ背骨の関節ごとの太さにそろえ、背中の線の他の点が凹んだ所でめり込む分も、転がりの補正の時点で持ち上げる（後からの一律の押し上げで体が5〜15cm浮いていた）。手をついている間のひじは外・前へ。
  開脚跳びの内股を修正：空中の脚を角度で決め、着手の間は股関節をあまり曲げず大きく開き（約75°）、脚を外へひねる（約35°、ひざ・つま先が外を向く）。
- 2026-11-21 浮きの解消：転がる間の高さを、胴・首・頭の実際の形（頂点）のいちばん低い所がちょうど上面に触れるように毎コマ合わせる。後からの押し上げは、転がる間の胴・頭と、手で押している間の腕には使わない（押し上げが前後へ広がって体が浮いていた）。浮きは0〜0.4cm（接し始めの数コマを除く）。
  かかえ込み跳びは、跳び箱を越える間に抱え込みを深くし（股関節約128°・ひざ約150°）、足首を曲げてつま先を上げる（つま先が跳び箱の奥に引っかかっていた）。
  実際の形（頂点）で測っためり込み：開脚跳び・かかえ込み跳び0cm、台上前転は手をつく直前の指2.3cmと、跳び箱の奥で腰1cmが残る。
- 2026-11-21 浮きの再修正：高さ合わせを「胴・首・頭の頂点すべて」「跳び箱の上（x 0〜0.8）にある部分だけ」で行い、浮きもめり込みも0〜0.5cmに（頭が着き始める0.92〜1.0秒を除く）。前回は頂点を間引いて測っていたため、測り方自体が浮きを見落としていた。
  腰まで転がった後は、おしりで跳び箱の端まで20cm進んでから下りる（端で太ももが箱に食い込んでいた）。着地は1.78秒に。
- 2026-11-21：手が浮いていた（手首の高さを手のひらの面より7.5cm上に置いていた）→手のひらの厚みの半分（1.7cm）に。側転も同じ誤りを修正。手は着く前から手のひらを下へ向け、手首は跳び箱の上面より下へ行かない。
  助走：脚を角度で動かす走り方（左右別の振り）に変え、ひじを曲げて腕を脚と反対に振る。前傾を少し強く。カメラを引いて助走全体が入るように。
- 2026-11-21：助走の腕はひじを約90°に曲げて体の横で前後に振り（ひじは後ろへ）、空中の手は手首をまっすぐ・手のひらを内向き（親指が上）にした。突き放し後も同じ。
- 2026-11-21：踏み切りで腕を後ろから前へ振る時に腕が胴を貫いていた→体の横を通す。着手で体重を受けて腕が少し曲がり（ひじ約45〜50°）、腕の力で押し返して伸びきってから離す（開脚跳び・かかえ込み跳び）。かかえ込み跳びは跳び箱の縁をつかむ手（手のひらと親指は上面、他の指は縁から側面へ曲げる）。
