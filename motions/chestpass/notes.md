# チェストパス：手本の読み取り記録

- 出典：DIAMOND BASKETBALL SCHOOL「チェストパス」（YouTube）。動画は置かない。
- 使った場面：0:48.9〜0:51.0（横から斜めの視点、ほぼ実際の速さ）。1秒30コマで手元・足元を拡大して読んだ。内部の時刻 = 動画の時刻 − 48.9秒。

## 字幕のこつ
- 手のひらで三角形を作ってボールを持つ
- ボールを少し下げてから押し出す／足を一歩前に出しながらパスを出す
- 人差し指は相手に向け、親指は下に向くくらいに／手首のスナップを使う

## 時刻表（内部の秒）
| 時刻 | 出来事 |
|---|---|
| 0〜0.30 | 構え（胸の前、親指どうしの三角形） |
| 0.30〜0.52 | 左足を踏み出す（0.52 着地、72cm前） |
| 0.30〜0.85 | ボールをおなかの高さへ下げる。後ろ足のかかとが上がり始める |
| 0.85〜1.15 | 低いまま止まる（ため） |
| 1.20〜1.37 | 押し出す。脚・腰が先、胴、最後に腕。手首は後ろに折ったまま |
| 1.37 | 放す（腕が伸びきる約0.05秒前） |
| 1.37〜1.43 | スナップ：手のひらが外、親指が下 |
| 1.43〜 | フォロースルー：腕は斜め上、後ろ足はつま先だけ残る |

## 接点駆動法での作り（2026-11-20）
- 接点：右足（固定、かかとを上げる）、左足（踏み出して着地）、両手＝ボールの表面（手のひらの面がボールに触れる位置から手首を逆算）。
- 置いたもの：ボールの通り道、骨盤の大まかな道筋、胴の傾き、手首の向き（5種）。
- 条件：持っている間に腕が届かなければ、腰を前へ運ぶ（＝前の足への体重移動。最大15cm、時間方向にならす）。
  最初は胴を前へ倒す補正にしたが、頭が下がって手本（放す時に胴が起きる）と逆になったため変えた。
- 放した後：手首の位置は手首の返しで動かさない（返しで手首が跳ね、ひじの加速度が約1500になった）。0.28秒かけて自由な軌道へ移る。

## 旧版との違い
`prototypes/chestpass-keyframe.html`（姿勢を数値で直接指定）は、ボールが腰より下（高さ0.55）まで下がり、放す位置が胸より低かった。新版は通り道を直接置いたので、おなかの高さ（0.80）・胸の高さ（1.05）になった。

## 推定した部分
- 体の奥側の腕・手首：手前側と左右対称。
- ボールの速さ：放す瞬間の通り道の速さ×2.5、最低秒速10m（根拠なし。利用者の指摘「勢いが小さい」で調整）。
