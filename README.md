# taiiku

体育の授業で「体の動かし方」を説明するための教材。関節が見える模擬人形で、手本の動きを回して・止めて・ゆっくり見られる。

## 動作

| 動作 | ページ | 状態 |
|---|---|---|
| 側転 | `motions/cartwheel/index.html` | 接点駆動法で作成 |
| チェストパス | `motions/chestpass/index.html` | 接点駆動法で作成 |
| 跳び箱（開脚跳び・かかえ込み跳び・台上前転） | `motions/vault/index.html` | 接点駆動法で作成 |
| 体育座り・前転 | `motions/roll/index.html` | 跳び箱の技の土台 |

各ページの操作：再生・速さ（とてもゆっくり／ゆっくり／実際の速さ／はやく）・局面へとぶ・見る向き・拡大縮小（2本指でも可）。

## 作り方

`docs/methodology/contact-driven-motion.md`（接点駆動法）。AIは `AGENTS.md` から読む。
